# 山河图主题写作约定

依据用户于 2026-11-10 确认的方向，适用于全部主题的地图简版与「学主题」详细版。后续内容修改先读本文件，并使用中文写作技能。

## 写成科普文章

正文面向希望理解地理的普通读者。先交代主题、范围与主要关系，再解释必要概念和机制，最后展开具体地区或案例。顺序依材料调整，不把所有文章写成同一套提纲。

同类对象尽量放在一起，用共同维度比较。例如高原比较高度、地表物质与改造过程，盆地比较围合、来水与出口。对照要解释差异的原因，不能只有名称和特征列表。

段落之间有承接，例子参与解释。保留准确、自然、有内容的句子；减少重复定义、反复提醒、空泛归结和强行设问。避免把文章写成操作指南、知识卡片拼接或考试提纲。自然表达不等于随意口语化，不编造观察、经历和情绪。

## 简版与详细版

- 地图简版是可以独立读懂的短文：交代对象、解释一两条关键联系、提出具体可观察的对照。观察入口负责地图操作，正文负责讲清知识。
- 详细版形成完整叙述，有总体介绍、机制解释和具体案例。案例只展开与本主题有关的内容，不重复粘贴地点百科简介。
- 简版、详细版和学习模块使用同一套事实与来源；不机械截取长文首段，也不把长文原样塞入侧栏。

## 图片、比较与资料

在文字难以独自说明位置、形态、过程或差异时配图。照片说明具体景观，地图说明真实空间，示意图解释机制，表格支持同维度比较。图紧邻相关段落，同一幅图在同一篇中原则上只出现一次。没有必要的装饰图不加。

已有合适图片优先复用；新增图片保留来源、许可与说明。概念示意标明非实测，不虚构地理范围、数据或地貌。图中的文字、正文和图注须一致。

保留来源、统计时期、分类口径和必要限定。重要疑点核对权威来源；文字编辑不声称重新核验了所有资料。保留旧章节地址、案例入口、收藏与分享兼容性，允许调整章节顺序和图片位置。

## 交付检查

逐篇检查主题入口、解释顺序、案例取舍、比较维度与图片位置，再跨篇检查是否机械套用同一表达。按项目流程同步生成数据、来源与哈希，检查桌面和手机的正文、图片、章节跳转及地图往返；部署遵循私密部署文档。

## 地貌两篇的组织（2026-11-12）

依用户本次确认，地貌形成与典型景观分成两篇完整科普长文：前篇解释岩石材料、地壳运动与风化侵蚀等过程，后篇比较常见地貌及中国典型景观。不以阅读时长限制必要解释；避免一地一节或每两段就加标题，让案例进入连续叙述。保留少量有实质分工的大章节，照片与示意图插在所解释的段落附近。中国与世界地形格局等其他主题保持各自范围。
